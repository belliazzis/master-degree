### AI in Medicine: BreastMNIST Image Classification

**Overview:**
A comparative analysis of deep learning architectures applied to medical image classification using the BreastMNIST dataset. 
The project focused on training different models, extracting performance metrics, and critically evaluating the results through a formal presentation 
and a written technical report.

**Models & Contributions:**
*   **Custom CNN (Built from scratch):** Implemented by Sonia Belliazzi.
*   **Vision Transformer (ViT-Tiny):** Implemented by Sonia Belliazzi.
*   **ResNet18:** Implemented by Giulia Marenghi.

**Technologies Used:** Python, PyTorch, NumPy, Matplotlib, Google Colab.
